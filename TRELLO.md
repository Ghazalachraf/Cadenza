## Configuration du tableau

**Listes** : `✅ Terminé` · `⬜ Desktop — reste` · `⬜ Mobile — 19 sections` · `⚙️ En cours` (max 1) · `🔴 Qualité` · `🚧 Arbitrage`

**Étiquettes** : 🔵 `Socle` · 🟢 `Desktop` · 🟡 `Mobile` · 🔴 `Qualité` · ⚫ `Arbitrage`

**Champs personnalisés** : `Est. (h)` · `Réel (h)` · `Node Figma` · `W3C OK`

### Checklist type — carte « section »

```
□ get_design_context sur le node
□ Assets téléchargés + optimisés (si nouveaux)
□ HTML sémantique
□ SCSS dans scss/layout/_xxx.scss (+ @use dans main.scss)
□ Compilation manuelle → css/main.css (bump ?v=N)
□ Rendu vérifié vs maquette
□ W3C Nu = 0 erreur
```

### Règles

- 1 seule carte dans `⚙️ En cours`
- Pas de clôture sans `W3C OK` coché
- Valeur douteuse dans la maquette → carte dans `🚧 Arbitrage`, jamais d'invention
- Remplir `Réel (h)` à la clôture pour recalibrer les estimations suivantes
